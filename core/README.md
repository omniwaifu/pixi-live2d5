# Live2D Cubism Core

This fork uses Cubism Core 6.0.1 from Cubism SDK for Web R5, paired with Framework 5-r.5. Download the matching files with:

```sh
bun run setup
```

The setup script extracts `live2dcubismcore.js` and `live2dcubismcore.d.ts` from the official Cubism SDK for Web R5 archive. These downloaded files are intentionally ignored by Git.
